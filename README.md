
# Week 7 Assignment: My Notes & The Report Builder

## Project Files

- my_notes.py - Writes, appends, reads and counts notes.
- my_notes.txt - Stores the four notes.
- report_builder.py - Reads CSV data and generates a learner report.
- hubs.csv - Contains learner names, hubs and scores.
- report.txt - Contains the generated learner report.
- README.md - Describes the project files.

## What happens if "a" is changed to "w"?

Changing append mode ("a") to write mode ("w") would erase the existing contents of the file before writing the new note.

Only the fourth note would remain instead of all four notes.
